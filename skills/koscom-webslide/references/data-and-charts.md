# 데이터와 차트

숫자·표·목록은 `index.html` 맨 아래 `<script type="application/json" id="deck-data">`에 둔다. 편집 모드의 「차트 데이터 편집」이 이 JSON을 고치고, 차트가 바로 다시 그려진다.

## charts — 캔버스 하나 = 키 하나
```json
"charts": {
  "c3bar": {"title": "03 · 직장인 보고서 인식", "kind": "hbar", "suffix": "%",
            "cols": ["항목", "값(%)", "색", "출처"], "types": ["t", "n", "c", "t"],
            "rows": [["보고서 스트레스를 느낀다", 65.4, "오렌지", "사람인 (2021.8)"],
                     ["과거 양식을 재활용해 쓴다", 36.8, "회색", "사람인 (2021.8)"]]}
}
```
| 필드 | 뜻 |
|---|---|
| `kind` | 범용 차트 종류 — `hbar`(가로 막대) · `vbar`(세로 막대) · `doughnut` · `line`. 전용 차트가 필요하면 스크립트의 `BUILD`에 같은 id로 함수를 넣는다(예시 덱의 c5·c18·c19 등) |
| `rows` | 행 = `[이름, 값, 색 이름, (출처·설명)]`. 막대 끝에 값이 찍히고, 네 번째 칸은 툴팁에 나온다 |
| `cols`·`types` | 편집 표의 머리글과 칸 종류 — `t` 글 · `n` 숫자 · `c` 색 · `d` 날짜(월/일) |
| `suffix` | 값 뒤 단위(%, 건, 시간 …) |
| `title` | 편집 창 제목 |

색 이름: `오렌지`(강조) · `네이비` · `진네이비` · `회색` · `진회색` · `연오렌지`. **강조할 막대 하나만 오렌지**, 나머지는 회색·네이비.

차트는 장에 들어올 때 그려지고, 마우스를 다시 대면 다시 차오른다. 캔버스 크기는 감싼 `.chart-box`의 height로 정한다.

## 그 밖의 데이터(예시 덱)
| 키 | 쓰는 장 | 모양 |
|---|---|---|
| `cat` | 템플릿 카탈로그(12장) | `[이름, 요약/상세, 구성, 표]` |
| `packs` | 팩 탭(14장) | `[이름, 주 문서, [형식…], 고유 내용, 추가 검수]` |
| `layers` | 상속 층(15장) | `[이름, 설명, 잠금 여부]` |
| `scenes` | 시연 타임라인(17장) | `[시각, 장면, 제목, 설명, 삽화 이름]` |

그 장을 지우면 데이터는 남아 있어도 문제없다(엔진이 건너뛴다). 화면에 데이터 글자를 그릴 때는 `data-bind="packs.0.1"`처럼 묶어 편집 모드에서 고칠 수 있게 한다.

## 숫자 원칙
- 모든 외부 숫자는 부록 B(출처)에 출처·날짜·성격을 적는다: 실측 · 외부 조사 · 언론 보도 · 벤더 발표 · 공식 문서 · 오픈소스
- 효과 숫자는 산식을 부록 A에 펼치고, 가정은 '가정'이라고 쓰고, 가정을 바꿔 보는 표를 함께 둔다
- 앞으로 늘어날 개수(템플릿 종류 등)는 'n종'으로 쓴다
